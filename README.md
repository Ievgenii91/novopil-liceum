# Офіційний вебсайт Новопільського ліцею Оліївської сільської ради

Сучасний, швидкий та адаптивний статичний вебсайт для **Новопільського ліцею Оліївської сільської ради Житомирського району Житомирської області** з інтегрованою **Git-based CMS** (Decap CMS) та автономним візуальним веб-редактором.

Розроблено відповідно до вимог статті 30 Закону України «Про освіту» та міжнародного стандарту доступності веб-контенту **WCAG 2.1 (ДСТУ ISO/IEC 40500:2015)**.

## 🏗️ Архітектура проєкту

Вебсайт побудований за принципом **JAMstack** та **Static Site Generation (SSG)**:
* **Безпека та надійність:** Немає вразливих баз даних SQL; 100% статичні HTML/CSS/JS файли неможливо зламати традиційними ін'єкціями.
* **Швидкість завантаження:** Статичні сторінки завантажуються миттєво (< 100 мс) з будь-якого хостингу чи CDN.
* **Git-based CMS:** Весь контент (сторінки, новини, оголошення, документи, реквізити) зберігається як звичайні файли у репозиторії Git (`.md` з frontmatter та `.json`). Будь-яке редагування створює комміт в історії Git.
* **Два інструменти адміністрування:**
  1. **Decap CMS (`/admin/`):** Офіційна Git-based CMS. Підтримує GitHub OAuth, Git Gateway, Netlify Identity та локальний бекенд.
  2. **Вбудований візуальний веб-редактор (`/admin/editor/`):** Зручний редактор з Live Preview для миттєвого оновлення контенту безпосередньо у локальному середовищі з автоматичною перезбіркою сторінок.

```
├── content/                     # Вміст сайту (джерело даних для Git CMS)

│   │   └── site.json            # Паспортні дані, телефони, адреса, статистика

│   │   └── registry.json        # Реєстр 28 оцифрованих першоджерел ліцею
│   ├── news/                    # Публікації новин ліцею (.md)

├── public/                      # Статичні файли, що копіюються в білд
│   ├── admin/
│   │   ├── index.html           # Інтерфейс Decap CMS
│   │   ├── config.yml           # Конфігурація колекцій Decap CMS
│   │   └── editor/index.html    # Вбудований візуальний CMS-редактор
│   └── assets/
│       ├── css/
│       │   ├── style.css        # Дизайн-система та адаптивні стилі
│       │   └── accessibility.css# Стилі доступності (WCAG 2.1)
│       ├── js/
│       │   ├── main.js          # Логіка навігації, фільтри пошуку, форми
│       │   └── accessibility.js # Модуль високої контрастності та озвучення
│       └── images/              # Векторний герб ліцею (logo.svg), ілюстрації
├── src/
│   ├── build.js                 # Генератор статичного сайту (чистий Node.js)
│   └── server.js                # Сервер розробки + Git CMS Backend API
├── dist/                        # Готовий статичний білд (готовий до деплою)
```

## ♿ Спеціальний режим для людей з порушенням зору (WCAG 2.1)

На сайті реалізовано повноцінну панель доступності (кнопка `👁️ Людям з порушенням зору` у верхній шапці):
* **Контрастні схеми:**
  * Звичайна тема;
  * Чорний текст на білому фоні (High Contrast B&W);
  * Інверсна тема (жовтий/білий текст на чорному фоні);
  * Синій текст на жовтому фоні (спеціальний офтальмологічний стандарт).
* **Масштабування шрифту:** Звичайний (16px), Збільшений (19px), Дуже великий (22px).
* **Спеціальний шрифт:** Перемикання на шрифт з підвищеною розбірливістю для людей з дислексією.
* **Регулювання інтервалів:** Збільшений міжрядковий та міжсимвольний інтервал.
* **Зображення:** Можливість зробити всі зображення чорно-білими або приховати для максимальної концентрації на тексті.
* **Озвучення тексту (Text-to-Speech):** Можливість прослухати виділений текст або зміст сторінки за допомогою синтезатора мовлення (Web Speech API).
* **Збереження вибору:** Налаштування автоматично зберігаються в `localStorage` браузера користувача.

## 🚀 Інструкція із запуску та розгортання

### 1. Локальний запуск:
```bash
# Запуск локального сервера розробки з Git CMS
npm start
# або
node src/server.js
# на Windows при відсутності глобального node в PATH:
.\node.cmd src/server.js
```
Після запуску відкрийте у браузері:
* Вебсайт ліцею: [http://localhost:3000/](http://localhost:3000/)
* Візуальний редактор контенту: [http://localhost:3000/admin/editor/](http://localhost:3000/admin/editor/)
* Панель Decap CMS: [http://localhost:3000/admin/](http://localhost:3000/admin/)

### 2. Збирання статичного сайту для публікації:
```bash
npm run build
# або
node src/build.js
```
Усі готові оптимізовані статичні файли генеруються у папку `dist/`.

### 3. Безкоштовний хостинг та деплой:
Папку `dist/` можна завантажити на будь-який сучасний сервіс:
* **GitHub Pages:** у налаштуваннях репозиторію вказати гілку `gh-pages` або каталог `dist/`.
* **Cloudflare Pages / Netlify / Vercel:** підключити репозиторій, команда збирання: `npm run build`, вихідний каталог: `dist`.

## 📝 Робота з Git-based CMS

Оскільки сайт використовує Git як базу даних, редагування матеріалів можна здійснювати двома шляхами:
1. **Через веб-інтерфейс (`/admin/` або `/admin/editor/`):** Зручні форми, поля вводу, завантаження медіа та автоматичне збереження.
2. **Безпосередньо у репозиторії:** Відкрийте будь-який файл у каталозі `content/` (наприклад, `content/settings/site.json` або `content/news/`), змініть текст і виконайте звичайний `git commit`. Під час наступного білду всі сторінки автоматично оновляться!
